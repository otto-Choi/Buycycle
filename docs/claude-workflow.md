# Claude 활용 계획

두 세션으로 구현한다.

## 역할 분담
| 세션 | 용도 |
|------|------|
| Sonnet (Medium) | 작성과 구현 대부분 |
| Opus (High) | 단계 종료 시 리뷰, 독립 검토. 특히 주문/금액/안전장치 코드 |

## 컨텍스트 운영
컨텍스트가 커지거나 구현 단계가 끝나면 주요 결정을 `docs/decisions.md`, 배운 내용을 `memory/<주제>.md`에 기록한 뒤 `/compact`를 실행한다. 인수인계용 스킬이나 훅은 두지 않는다. 필요한 문제가 실제로 생기면 그때 도입한다.

## Opus 리뷰 절차
- 입력: `docs/plan.md`, `docs/decisions.md`, `git diff`
- 구현 세션의 맥락(대화 요약 등)은 넘기지 않는다. 구현자의 판단을 물려받으면 독립 검토의 의미가 사라진다.
- 결과는 `docs/log.md`에 요약하고, 결정이 바뀌면 `docs/decisions.md`에 새 항목으로 추가한다.
