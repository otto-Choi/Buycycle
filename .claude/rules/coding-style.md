# 코딩 스타일

## 주석
- 기본적으로 주석을 쓰지 않는다. 이름과 구조로 설명한다.
- 코드만으로 알 수 없는 사실만 허용한다: 외부 API 명세에서 온 제약(필드 단위 등), 비직관적인 수치의 출처, 특정 버그를 피하는 우회의 이유.
- 금지:
  - 구현의 한계를 설명하는 주석 ("단순화를 위해 생략", "현재는 ~만 지원")
  - 이후 구현을 암시하는 주석 (`TODO`, `FIXME`, "추후 개선", "나중에 구현")
  - 코드가 하는 일을 반복하는 주석
  - 변경 경위를 설명하는 주석 (`docs/log.md`나 커밋 메시지에 쓴다)
- 한계와 이후 작업은 코드에 적지 않고 `docs/plan.md`나 `docs/decisions.md`에 남긴다.
