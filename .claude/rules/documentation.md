# 문서화 규칙

## 작업 로그 (`docs/log.md`)
- 기능이나 단계 단위로 기록한다. 개별 파일 수정마다 쓰지 않는다.
- `## YYYY-MM-DD` 헤더 아래에 한 줄씩, 최신 항목을 맨 아래에 추가한다.
- 기능 하나가 끝나거나 구조·설정이 바뀌었을 때 기록한다.

## 의사결정 기록 (`docs/decisions.md`)
- 선택지가 있는 결정을 내릴 때 근거를 남긴다. 구조, 기술 스택, 방식 선택이 해당한다.
- 형식: `## D-번호. 제목 (날짜)` 아래에 결정, 근거, 검토한 대안.
- 번호는 순서대로 증가시키고, 기존 항목은 고치지 않는다. 결정이 바뀌면 새 항목을 추가하고 이전 항목을 참조한다.

## 메모리 (`memory/`)
- 상세 기록은 `memory/<주제>.md`에 두고, `memory/memory.md`에는 한 줄 설명과 링크만 둔다.
- 메모리 파일을 만들거나 삭제하면 `memory.md` 목록을 같이 갱신한다.
